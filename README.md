# 🎨 Elegant Works - Professional Portfolio

A modern, responsive professional portfolio website showcasing skills, work samples, and educational background. Built with Bootstrap, Swiper.js, and vanilla JavaScript for an elegant and interactive user experience.

## ✨ Features

- **Splash Screen** - Eye-catching loading animation (2-second intro)
- **Responsive Design** - Fully responsive layout using Bootstrap Grid system
- **Interactive Carousel** - Swiper.js carousel for displaying work samples with smooth transitions
- **Modal Dialogs** - Organized modals for Work Samples and Education information
- **Smooth Animations** - Scroll-triggered section animations for engaging user experience
- **Social Media Integration** - Quick links to LinkedIn, Instagram, Twitter, and email
- **Professional Summary** - Detailed introduction highlighting expertise in:
  - Microsoft Excel (Advanced data analysis & automation)
  - Microsoft Word (Professional document creation)
  - Web Frontend Development (HTML, CSS, JavaScript)
  - Data Analysis & Reporting

## 🛠️ Tech Stack

- **HTML5** - Semantic markup structure
- **CSS3** - Custom styling with Bootstrap utilities
- **JavaScript (Vanilla)** - DOM manipulation and interactive features
- **Bootstrap 5** - Responsive grid system and components
- **Swiper.js** - Touch-friendly carousel/slider functionality
- **jQuery** - DOM event handling and modal management
- **Font Awesome** - Icon library for social media links
- **Bootstrap Icons** - Additional icon set
- **SweetAlert** - Beautiful notification alerts

## 🚀 Getting Started

1. **Clone or download** this repository
2. **Open** `index.html` in your web browser
3. **Explore** the portfolio features - click on buttons to view work samples and education

No build process or dependencies installation required!

## 📋 Sections

- **Introduction** - Professional summary and key skills
- **Work Samples** - Interactive carousel displaying portfolio projects
- **Education** - Educational background and qualifications
- **Contact** - Social media links and contact information

## 📱 Responsive Breakpoints

The carousel adapts to different screen sizes:
- **Mobile** (0px): 1 slide per view
- **Tablet** (520px): 2 slides per view
- **Desktop** (950px): 3 slides per view
